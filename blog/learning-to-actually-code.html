learning to actually code

november 2026

a lot of what's on my github was built with heavy help from ai coding tools. that let me move fast and explore problems i care about, like how robust rna-seq results really are. but at some point i noticed a gap between the projects i could describe and the code i could write and debug myself.

so i'm closing that gap on purpose. over the next weeks i'm working through the fundamentals in one connected project: building a small character-level gpt from scratch. python basics, numpy, pandas, gradient descent by hand, pytorch, attention, and finally a full transformer trained on my own laptop.

the rule i'm following: type every line, break things on purpose, and don't move on until i can explain a piece without looking.

i'll write short notes here as i go: what clicked, what confused me, and what the loss curves looked like. if you're also learning this, i hope they're useful.
